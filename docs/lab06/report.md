# Звіт про виконання лабораторної роботи #06
**Тема:** Generics та колекції .NET
**Варіант:** 2 (Інтернет-магазин)

---

## Мета роботи
Закріпити практичні навички використання узагальнених типів і методів у C#, обмежень узагальнених типів та основних generic-колекцій .NET; навчитися використовувати `List<T>`, `Dictionary<TKey, TValue>`, `IEnumerable<T>` та `yield return` для побудови типобезпечної моделі даних наскрізного проєкту.

---

## Опис виконаної роботи (Варіант 2: Інтернет-магазин)
1. **Generic-контейнер та каталог товарів:**
   - Для швидкого доступу до товарів за унікальним ідентифікатором (ID) використано `Dictionary<int, Product>`.
   - Для зберігання товарів у кошику покупця використано колекцію `List<Product>`.

2. **Ітератор з `yield return`:**
   - Реалізовано метод `GetProductsByCategory(string category)`, який повертає `IEnumerable<Product>` і за допомогою ключового слова `yield return` здійснює послідовний перебір елементів без створення додаткових проміжних масивів у пам'яті.
