# Звіт про виконання лабораторної роботи #03
**Тема:** Успадкування та поліморфізм у C#
**Варіант:** 2 (Інтернет-магазин)

---

## Мета роботи
Набути практичних навичок використання механізмів успадкування та поліморфізму в об'єктно-орієнтованих програмах мовою C#. Навчитися проєктувати ієрархії класів, визначати спільні характеристики у базових абстрактних класах, розширювати їх у похідних класах, а також використовувати ключові слова `virtual` та `override` для реалізації поліморфної поведінки об'єктів.

---

## Опис виконаної роботи (Варіант 2: Інтернет-магазин)
1. **Створення ієрархії класів товарів:**
   - Створено абстрактний базовий клас `Product`, який містить спільні властивості (`Name`, `Category`, `BasePrice`, `Quantity`) та базові методи управління кількістю.
   - Створено похідні класи спеціалізованих товарів: `ElectronicsProduct` (з додаванням гарантії), `FoodProduct` (з терміном придатності) та `ClothingProduct` (з розміром).

2. **Реалізація поліморфізму:**
   - У базовому класі `Product` визначено абстрактний метод `CalculatePrice()` та віртуальний метод `DisplayInfo()`.
   - У кожному похідному класі реалізовано специфічне перевизначення (`override`) цих методів з урахуванням особливостей категорії товару.

3. **Поліморфна обробка в головній програмі (`Program.cs`):**
   - Створено колекцію типу `List<Product>` для зберігання об'єктів різних категорій товарів.
   - За допомогою циклу `foreach` здійснено поліморфний обхід колекції та виклик методів через базові посилання.
