# Звіт про виконання лабораторної роботи #09
**Тема:** Сучасні можливості C# для моделювання даних
**Варіант:** 2 (Інтернет-магазин)

---

## Мета роботи
Набути практичних навичок застосування сучасних можливостей C# для моделювання даних; навчитися використовувати `record` і `record struct`, розрізняти типи значень та посилань, опрацьовувати `nullable reference types`, застосовувати `pattern matching`, індекси й діапазони.

---

## Опис виконаної роботи (Варіант 2: Інтернет-магазин)
1. **Створення записів (`record` та `record struct`):**
   - Розроблено незмінну модель `ProductSnapshot` (record-клас) для формування зведеної інформації про товар та `PriceValue` (record struct) для інкапсуляції цінового значення.
   - Продемонстровано створення зведеної копії з використанням виразу `with`.

2. **Опрацювання Nullable Reference Types:**
   - Увімкнено підтримку типів, що допускають значення `null`, для необов'язкових полів (наприклад, опису товару) та реалізовано безпечну перевірку через pattern matching.

3. **Pattern Matching та діапазони (`..`):**
   - Реалізовано класифікацію товарів за ціною за допомогою `switch`-виразів.
   - Застосовано оператор діапазону для виділення префіксів із кодування товарів (`SKU`).
