# Звіт про виконання лабораторної роботи #05
**Тема:** Generics та узагальнені методи в C#
**Варіант:** 2 (Інтернет-магазин)

---

## Мета роботи
Набути практичних навичок використання узагальнених типів і методів у програмах мовою C#, навчитися створювати узагальнені класи, використовувати параметри типу та обмеження узагальнених типів `where`, застосовувати generics для повторного використання коду та типобезпечної роботи з об'єктами.

---

## Опис виконаної роботи (Варіант 2: Інтернет-магазин)
1. **Узагальнений каталог (`Catalog<T>`):**
   - Розроблено узагальнений клас `Catalog<T>`, який забезпечує зберігання та керування колекцією об'єктів предметної області без дублювання коду.

2. **Узагальнений метод пошуку (`Find<T>`):**
   - Реалізовано узагальнений метод `Find<T>` для фільтрації колекцій за допомогою делегатів `Func<T, bool>`.

3. **Обмеження параметра типу (`where T : Product`):**
   - Створено узагальнений метод `DisplayProductNames<T>`, який працює виключно з типами, що успадковуються від базового класу `Product`, забезпечуючи типобезпечний доступ до його властивостей.
