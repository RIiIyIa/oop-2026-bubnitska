# Звіт про виконання лабораторної роботи #01
**Тема:** Створення та організація проєкту на C#/.NET у середовищі Visual Studio / VS Code


**Варіант:** 2 (Інтернет-магазин)

---

## Мета роботи
Ознайомитися з організацією програмного проєкту на платформі .NET, сформувати практичні навички створення консольного проєкту мовою C#, організації структури предметної області та започаткувати розробку наскрізного проєкту.

---

## Опис виконаної роботи (Варіант 2: Інтернет-магазин)
1. **Створення проєкту:**
   - Створено консольний .NET проєкт `ShopApp` у папці `src/ShopApp/`.
   - Створено простір імен `ShopApp.Models` для сутностей предметної області.

2. **Створення класів предметної області:**
   - У папці `Models/` створено клас `Product` із властивостями:
     - `Name` (назва товару, `string`)
     - `Price` (ціна товару, `decimal`)
     - `Category` (категорія, `string`)
   - Створено клас `Customer` із властивістю:
     - `Name` (ім'я покупця, `string`)

3. **Створення та використання об'єктів (у `Program.cs`):**
   - Підключено простір імен `ShopApp.Models`.
   - Створено по два об'єкти класів `Product` та `Customer`.
   - Виведено інформацію про створені об'єкти в консоль.
